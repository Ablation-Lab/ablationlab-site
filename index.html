01/Research

Research

Evolving Review Councils

When an AI agent reviews code, it usually works alone. This project asks whether a council of AI reviewers catches more problems than one reviewer at the same cost, and whether councils can evolve to get better over generations. Repeating the runs at different council sizes, on tasks of different complexity, shows where one more reviewer stops paying for itself.

Status Planning stage. The pilot is done; the formal experiment, a council calculator, the write-up and the raw run logs will be added to the repo as they’re produced.

Human in the Loop

When AI agents can talk to each other directly, what does keeping a human in the middle actually buy you? The plan, with the hypotheses, the setups to compare and how results are measured, is published in the repo.

Status Planning. Nothing has been tested yet.

02/Windows app

Windows app

  • Stowdeck

    Desktop app · Windows 10 or 11 (64-bit)

    A Windows app for your Claude Code sessions: see what’s running now and what you worked on in the last 24 hours, 3, 7 or 30 days, save your whole set of sessions as a snapshot and reopen them in one click, each resuming its conversation, and start new sessions. A Terminals tab lists your other terminal windows, such as other CLI agents and dev servers, so they can go in a snapshot too.

03/Plugins

Claude plugins

Each adds a skill to Claude. Each repo’s README has install steps, and explains exactly what the tool runs, reads and sends.

  • Council Dial

    Works in Claude Code · needs Node.js 18+ · install as council-dial

    Has Claude run a review council of subagents set up the way you choose: specialised or generalist reviewers, a judge, a pooled list or a majority consensus, and optional debate, sequential and single-reviewer baseline runs. Claude tells you how many subagents a run will use and waits for your yes, and each run goes into a log so you can compare council types over time.

  • Cutproof

    Works in Claude Code on Windows · needs ffmpeg · install as cutproof

    Turns a rendered video or a Remotion project into a review pack Claude can check without watching it. It flags typos, numbers that don’t match the voiceover, text shown too briefly to read, and audio problems such as clipping, clicks and long silences, each with its timestamp in the video.

  • Lore Lookup

    Works in Claude Code and the Claude app · install as lore-lookup

    When you ask about Claude, Claude Code or the Claude apps, Claude looks the answer up in Anthropic’s online docs, help pages and release notes and replies with links to the pages it used, instead of answering from memory. If something can’t be confirmed there, Claude says so.

  • Seaready

    Works in Claude Code · needs Node.js 18+ and git 2.44+ · install as seaready

    Checks a plugin repo before you submit it to Anthropic’s plugin directory, to catch many of the problems the portal would block or hold it for, such as plugin names already taken, hidden Unicode and personal emails in the git history. It then drafts your answers for the submission form.

  • Stowdeck

    Works in Claude Code on Windows · needs the Stowdeck app · install as stowdeck

    Gives Claude a skill and commands to list your running and recent Claude Code sessions and saved snapshots, save a snapshot and open the Stowdeck app.

  • Bench Diary

    Works in Claude Code · needs Node.js 18+ · install as bench-diary

    Keeps your research notes up to date as you work. Turn it on in a conversation, and Claude logs the notes, decisions, anecdotes and experiment ideas you mention into the right Markdown doc in your project. Each time, it tells you in one line what it logged, with an undo, and it leaves out secrets and personal details.

  • Langparity

    Works in Claude Code · needs Node.js 18+ · install as langparity

    Checks translations of your app or docs against their source; it doesn’t translate for you. A local script flags missing or added text, broken placeholders and formatting, changed numbers and text left untranslated. Claude then reads each pair for meaning and tone and suggests a corrected translation for each problem it confirms.

  • Tangent Jar

    Works in Claude Code · needs Node.js 18+ · install as tangent-jar

    Helps you stay on your main task in a focus session you start. When a side question comes up, Claude parks it in a list in your project for later (asking first unless you said “park this”) and nudges you back. You get three tangent tokens per session; after that Claude still parks each tangent, with some playful pushback.

04/Install

Install from the Ablation Lab marketplace

In Claude Code, add the marketplace once:

/plugin marketplace add Ablation-Lab/plugins

Then install a plugin by the name after “install as” on its card, for example:

/plugin install tangent-jar@ablation-lab

05/How they were built

How these tools were built

The plugins were built with Claude Code. Seaready, the plugin submission checker, was built first and run on its own repository, then used to check Tangent Jar, Bench Diary, Langparity and Council Dial before they were submitted to the Claude plugin directory.

Those four also went through a review council of three reviewers and a judge, then two rounds of fixes, each rechecked by a fresh reviewer. The issues left after that are listed under Limits in each README. Seaready is our own pre-check; the directory’s validation and Anthropic’s reviewers make the actual decision.
