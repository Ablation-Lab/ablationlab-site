01/Current project

Evolving review councils

When an AI agent reviews code, it usually works alone. This project asks whether a council of reviewers catches more problems than one reviewer at the same cost, and whether councils can improve over generations. Here the council evolves: each generation tries to beat the best version so far, and a change is kept only if it beats the best version on a fixed set of hard tests, with held-out tests the agents never see to catch gaming.

Repeating the runs at different council sizes, on tasks of different complexity, shows where one more reviewer stops paying for itself.
